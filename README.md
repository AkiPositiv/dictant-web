# Проверка диктантов — электронный журнал

Веб-приложение для учителя: группы → ученики → работы. Работу можно загрузить файлом
(DOC, DOCX, PDF, JPG/JPEG, PNG, WEBP, HEIC, RTF, ODT, TXT), фотографиями страниц или текстом.
ИИ (Google Gemini, бесплатно) распознаёт текст, в том числе рукописный, и находит ошибки,
а журнал показывает баллы по критериям: что выполнено правильно, за что и сколько снято, и ставит оценку 1–5.

Интерфейс на русском и узбекском языках, работает на телефоне и компьютере, есть светлая и тёмная тема.

## Как это устроено

- Только HTML, CSS и JavaScript, без сервера и без сборки.
- Данные (группы, ученики, работы и файлы) хранятся в браузере (IndexedDB) **на этом устройстве**.
  На другом устройстве журнал будет пустым. Чтобы перенести данные, в «Настройках» скачайте резервную копию и загрузите её на другом устройстве.
- Ключ Gemini хранится только в браузере учителя и в коде не содержится.

```
index.html
css/style.css
js/i18n.js      тексты интерфейса (RU / UZ)
js/grading.js   баллы по критериям и оценка по шкале
js/settings.js  настройки (localStorage)
js/db.js        хранилище IndexedDB, экспорт и импорт
js/files.js     чтение файлов (doc, docx, odt, rtf, pdf, изображения)
js/ai.js        запросы к Google Gemini
js/app.js       экраны и навигация
```

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `dictant-web`.
2. Загрузите в него **содержимое** этой папки так, чтобы `index.html` лежал в корне репозитория
   (через кнопку «Add file → Upload files» или командами ниже).
3. Откройте **Settings → Pages**, в поле «Source» выберите «Deploy from a branch», ветку `main`, папку `/ (root)` и нажмите «Save».
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/dictant-web/`.

```bash
cd dictant-web
git init
git add .
git commit -m "Dictation checker web app"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/dictant-web.git
git push -u origin main
```

Проверить сайт без GitHub можно, просто открыв `index.html` в браузере.

## Бесплатный ключ Gemini

1. Откройте https://aistudio.google.com/apikey и войдите через аккаунт Google.
2. Нажмите «Create API key» и скопируйте ключ (он начинается с `AIza…`).
3. На сайте откройте «Настройки», вставьте ключ и нажмите «Сохранить и проверить ключ».
   Список доступных моделей загрузится автоматически. Рекомендуется модель `gemini-flash-latest`: она всегда указывает на актуальную быструю модель. Если выбранную модель Google отключит, сайт сам переключится на неё.

У бесплатного ключа есть лимит запросов в минуту и в день. Если он превышен, подождите минуту.

## Как ставятся баллы и оценка

Перед загрузкой работы учитель указывает, **на сколько баллов** работа (от 1 до 100).
Максимум делится по критериям:

| Критерий | Доля | Для работы на 100 баллов |
|---|---|---|
| Орфография | 50% | 50 |
| Пунктуация | 30% | 30 |
| Грамматика | 20% | 20 |

По каждому критерию ИИ пишет, **что выполнено правильно**, и **за какие ошибки сколько баллов снято**.
Ориентир: грубая ошибка снимает около 10% максимума критерия, негрубая около 5%, повторная ничего.
Сайт сам пересчитывает арифметику: баллы критерия равны максимуму минус снятия (не ниже нуля), итог — сумма критериев.

Оценка 1–5 выставляется по проценту от максимума (пороги можно изменить в «Настройках»):

| Оценка | Процент |
|---|---|
| 5 | 90–100% |
| 4 | 75–89% |
| 3 | 50–74% |
| 2 | 25–49% |
| 1 | меньше 25% |

Учитель всегда может поставить оценку вручную.
